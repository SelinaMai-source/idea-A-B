## 2026-11-01 实现与偏差（算法落地，仍无 C-v1）

- 实现共享 `e-BH`、FDR/TPR/TPP/Power/SupFDR、seed、序列化；四个算法包改为独立复现，不发明新方法。
- **Lévy-stable**：原文只给污染概率 1/10、location 1000、skewness 0.5，**未给**稳定性指数与尺度。代码用 `alpha=1.5`、`scale=1.0`（`scipy.stats.levy_stable` S0）。不得假装论文指定了它们。
- **Algorithm 2**：每步更新 e-process 与 e-BH，不是「仅 t>KB 才更新」。
- **Algorithm 1**：trimmed-mean LCB 的 argmax（不是 raw mean）。
- **Algorithm 3 / Figure 3 / Figure 4**：本切片未跑。Heavy-tail 与 multi-agent 保持 `NOT_RUN`。
- **e-PS Student-t**：实现为 location-shift \(t_5+\theta\)，不是 noncentral-t。
- **SCORE+**：只在 `assume_cpqd=True` 时调用；无 CPQD 则 `N/A`，不是 0。
- **UAI**：`neilzxu/eclosure` 是离线 e-Closure（arXiv:2509.02517），不是这篇在线 closed/donation。`.venv` 中 C++ `_cebh` 不可用（`ImportError`，未强行编译）。在线方法走独立 Python。Donation 用 \(O(t)\) 而非文中 \(O(\log t)\) 树。r-LOND 校准器用 \(E=1/P\)。
- **P1-A**：horizon 取 Algorithm 2 的 \(KB=22600\)。代码对 \(t\le KB\) 均匀抽样，故 E-process-based 与 Uniform **抽样规则相同**，不得排名。Mean-based \(t(1)\approx 3240\)/臂，22600 不够初始化全部 50 臂。
- **e-PS Oracle 在 P1-A**：假设备择改为共同协议 \(\mu=1\)，不是原文 \(\theta_{\mathrm{alt}}=0.02k\)（adapted）。
- **污染下 Greedy / e-PS**：非鲁棒 increment，只作 `NOT_COMPARABLE` stress test。
