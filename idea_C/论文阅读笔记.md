## 1. AAAI 2026 — On the Robustness of Bandit Multiple Testing

- **作者 / 出处:** Zhengyu Zhou, Weiwei Liu. AAAI 2026 Main. https://ojs.aaai.org/index.php/AAAI/article/view/40148
- **问题:** 带污染的 bandit 多重检验：在 Huber 污染下尽快达到目标 TPR，同时 anytime FDR 控制。
- **动机:** 已有 bandit MT（Jamieson & Jain；Xu, Wang, Ramdas 2021）默认干净观测；药筛 / A/B 中部分样本可被任意污染。
- **方法:** Mean-based（α-trimmed mean，Algorithm 1）与 E-process-based（Algorithm 2）自适应抽样，再用 e-BH。Heavy-tail 无限方差走 Algorithm 3。多 agent 合并 e-value 为 Algorithm 4（v0 默认跳过）。
- **公式（待实现时再抄全）:** 污染混合 \( (1-\varepsilon)P_i+\varepsilon Q_i \)；e-process (5) 建议 \(\lambda=\sqrt{\varepsilon}/(2\sigma)\)；trimmed-mean 不确定项 \(U=O(\sigma\sqrt{\varepsilon\log(1/\varepsilon)})\)。
- **定理:** 样本复杂度分解 null / non-null（Theorem 8 等）；污染下可识别需要 Assumption 5（正臂不被污染翻转符号）。
- **假设:** 子高斯（Assumption 4）；污染水平 \(\varepsilon\) 已知量级；heavy-tail 用 \(p=1.85,\kappa=50\)。
- **原 baseline / benchmark / figure:** Uniform / Mean-based / E-process-based。Fig 1–2：\(P_i=N(\mu_i,1)\)，Lévy 污染 \(1/10\) loc 1000 skew 0.5，\(\delta=0.05\)，\(|H_1|\in\{2,\lfloor\log K\rfloor,\lfloor\sqrt{K}\rfloor\}\)，**500 trials**。Fig 3：t(2)，\(K=50\)，\(|H_1|=2\)，non-null mean 5。
- **局限:** 无官方代码；Figure 1 的 K 在 HTML 摘录中未给出数值；依赖已知 \(\varepsilon\)；污染下非鲁棒 e-process 不能当反例去打原文定理。
- **复现发现:** 尚未实现，NOT_RUN。
- **gap:** 与 e-PS 的「自适应抽样 + e-BH」接口相近，但鲁棒估计 / 污染模型不同。C1 候选，无实验前不 Go。
- **novelty risk:** 与 NeurIPS 2021 e-BMT 易混淆；任何独立实现必须对照 Figure 1/2 公式而非 `neilzxu/e_bmt`。

## 2. ICML 2026 — SCORE

- **作者 / 出处:** Qi Kuang, Bowen Gang, Yin Xia. ICML 2026 Main. PMLR v306. https://proceedings.mlr.press/v306/kuang26c.html
- **问题:** 在线 e-value FDR 把超过阈值的证据丢掉（overshoot），功率偏低。
- **动机:** \(I(y\ge 1)\le y-(y-1)_+\)，把超额证据退回 alpha-wealth。
- **方法:** SCORE-LOND / SCORE-LORD / SCORE-SAFFRON；SCORE+ 用最新拒绝数回溯分母（需 CPQD）。
- **公式:** \(O_j=(\alpha_j e_j-1)_+\)，\(C_j^{\mathrm{SCORE}}=(C_j-O_j)_+\)。SAFFRON 还先收紧 candidate penalty。§6.1 e-value \(e_t=\phi(X_t;3,6)/\phi(X_t;0,1)\)。
- **定理:** 有限样本 FDR；SCORE 阈值点态不低于原方法；SCORE+ 的 FDR 在 CPQD 下成立。
- **假设:** 条件 e-validity；SCORE+ 另需 Conditional Positive Quadrant Dependence。独立 e-value + 单调阈值是 CPQD 的充分条件。
- **原 baseline / benchmark / figure:** e-LOND/LORD/SAFFRON。§6.1 独立 Gaussian mixture，\(T=1000\)，\(\pi_1\in\{0.3,0.8\}\)，\(\alpha=0.05\)，500 reps。§6.2 AR exponential（v0 默认后置）。
- **局限:** 无官方代码；SCORE+ 在不满足 CPQD 时不能用；真实数据 conformal e-value 文中不用 SCORE+。
- **复现发现:** 尚未实现，NOT_RUN。
- **gap:** 与 UAI donation / closed 都是「把多余财富再分配」，计算与假设不同。C2 候选。
- **novelty risk:** 若只把 SCORE 写成「拒绝后加点 α」即与原文不符，也没有新方法。

## 3. UAI 2026 — online e-closure and compound e-values

- **作者 / 出处:** Ziyu Xu, Lasse Fischer, Aaditya Ramdas. UAI 2026，PMLR v337. **非 CCF-A Main。** https://proceedings.mlr.press/v337/xu26a.html
- **问题:** 任意依赖下改进在线 FDR / **SupFDR**，并降低 closed 方法的 \(O(t^2)\) 成本。
- **动机:** 离线 e-closure 不能直接搬到无穷流；donation 构造在线 compound e-value，单步 \(O(\log t)\)。
- **方法:** Closed e-LOND / r-LOND（动态规划 \(O(t^2)\)）；Donation e-LOND / r-LOND（\(O(\log t)\)）。二者都严格改进 e-LOND，但不一定彼此点态支配。
- **公式:** e-LOND \(\alpha_t=\delta\gamma_t(|R_{t-1}|+1)\)；默认 \(\gamma_t=1/(t(t+1))\)。Donation 用超额财富 \(\bar W_t\) 抬高当前阈值。
- **定理:** online SupFDR e-closure（Theorem 1）；donation e-LOND 控制 SupFDR 且严格改进 e-LOND（Theorem 8）。
- **假设:** 任意依赖 e-value / p-value；increasing e-collection；\(\gamma\) 可和为 1。
- **原 baseline / benchmark / figure:** e-LOND, r-LOND, closed, donation。Local dependence：\(m=200\)，\(\mu_0=0,\mu_1=3\)，\(L=100\)，\(\Sigma_{ij}=0.5^{|i-j|}\)（\(|i-j|\le L\)），\(\delta=0.1\)，**200 trials**。Runtime 网格可到 \(m=3000\)（默认跳过）。NYC taxi 默认跳过。
- **局限:** 公开 `neilzxu/eclosure` 对应离线论文 arXiv:2509.02517（`closedeBH`/`closedBY`），不是 UAI 在线算法。`evalue-omt` 是 AISTATS 2024。Mac 上若 C++ 编不过，独立 Python 必须标 deviation。
- **复现发现:** 已浅克隆，尚未跑实验。
- **gap:** 与 SCORE overshoot refund 同属财富再分配，错误度量（FDR vs SupFDR）与计算复杂度不同。
- **novelty risk:** 把 UAI 标成 CCF-A、或把离线 e-Closure 仓库当成 UAI 2026 官方在线代码，都会造成 venue / 复现错误。

## 4. arXiv:2609.26651 — e-PS

- **作者 / 出处:** Zhanran Lin, Wanteng Ma, Zhimei Ren, Yuting Wei. arXiv:2609.26651，**预印本，不是已发表 CCF-A。**
- **问题:** 自适应选臂做多重检验：用尽量少的样本发现全部 non-null，anytime FDR，拒绝集 nested。
- **动机:** e-value 既做检验（e-BH）又做抽样奖励（log increment 的后验抽样）。
- **方法:** Algorithm 1 e-PS：每个假设用 surrogate reward 上的后验抽一个合成奖励，抽最大者；e-BH 得到 \(R_t\subseteq R_{t+1}\)。
- **公式:** 条件有效 e-increment；Gaussian 均值检验 KL 与 sub-Gaussian log-LR；实现用 \(v_{k,t}=1.1\hat\sigma_{k,t}^2\)。
- **定理:** 任意停时 FDR；nested rejection；发现全部 non-null 的高概率样本复杂度（simple-vs-simple 有匹配下界）。
- **假设:** 条件有效 e-increment；log e-increment 的 sub-Gaussian / 方差代理。
- **原 baseline / benchmark / figure:** Uniform；Greedy（Xu et al. 2021）。§6：\(K=50\)，1D Gaussian 与 1D Student-t(5)；simple-vs-simple vs composite 分开；\(\alpha=0.05\)；**500 trials**。跳过 5D、Jester、LLM watermark。
- **局限:** 无官方代码；方差代理需调；污染下非鲁棒 increment 没有文中保证。
- **复现发现:** 尚未实现，NOT_RUN。
- **gap:** 与 AAAI robust bandit 同是自适应抽样 + 多重检验，污染模型几乎没覆盖。C1 的对照轴。
- **novelty risk:** 预印本状态可能变；不能把 e-PS 写成已发表 CCF-A baseline。
