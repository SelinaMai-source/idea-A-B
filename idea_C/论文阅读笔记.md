## 1. AAAI 2026 — On the Robustness of Bandit Multiple Testing

- **作者 / 出处:** Zhengyu Zhou, Weiwei Liu. AAAI 2026 Main. https://ojs.aaai.org/index.php/AAAI/article/view/40148
- **问题:** 带污染的 bandit 多重检验：在 Huber 污染下尽快达到目标 TPR，同时 anytime FDR 控制。
- **动机:** 已有 bandit MT（Jamieson & Jain；Xu, Wang, Ramdas 2021）默认干净观测；药筛 / A/B 中部分样本可被任意污染。
- **方法:** Mean-based（α-trimmed mean，Algorithm 1）与 E-process-based（Algorithm 2）自适应抽样，再用 e-BH。Heavy-tail 无限方差走 Algorithm 3。多 agent 合并 e-value 为 Algorithm 4（v0 默认跳过）。
- **公式:** 污染混合 \((1-\varepsilon)P_i+\varepsilon Q_i\)；e-process 建议 \(\lambda=\sqrt{\varepsilon}/(2\sigma)\)；trimmed-mean 不确定项 \(U=O(\sigma\sqrt{\varepsilon\log(1/\varepsilon)})\)。Algorithm 2 burn-in \(B=\lceil 4\varepsilon^{-1}\log(4K/\delta^2)\rceil\)，\(KB\) 在 \(K=50,\delta=0.05,\varepsilon=0.1\) 时为 22600。
- **定理:** 样本复杂度分解 null / non-null（Theorem 8 等）；污染下可识别需要 Assumption 5（正臂不被污染翻转符号）。
- **假设:** 子高斯（Assumption 4）；污染水平 \(\varepsilon\) 已知量级；heavy-tail 用 \(p=1.85,\kappa=50\)。
- **原 baseline / benchmark / figure:** Uniform / Mean-based / E-process-based。Fig 1–2：\(P_i=N(\mu_i,1)\)，Lévy 污染 \(1/10\) loc 1000 skew 0.5，\(\delta=0.05\)，\(|H_1|\in\{2,\lfloor\log K\rfloor,\lfloor\sqrt{K}\rfloor\}\)，**500 trials**。Fig 3：t(2)，\(K=50\)，\(|H_1|=2\)，non-null mean 5。
- **局限:** 无官方代码；Figure 1 的 K 在 HTML 摘录中未给出数值；依赖已知 \(\varepsilon\)；污染下非鲁棒 e-process 不能当反例去打原文定理。Lévy 稳定性指数/尺度原文未给。
- **复现发现:** 独立实现。Lévy 代码用 \(\alpha=1.5\)、scale=1.0。Alg2 每步更新 e-process（非仅 t>KB）。Alg1 为 trimmed-mean LCB argmax。
  - v0 P0 Gaussian（K=50，|H1|=2）smoke H=400：三法 TPR=0。pilot H=4000 30-seed：Uniform / E-process TPR=0.2、SAT=3520.5；Mean SAT=`NOT_RUN`。horizon ≤KB，**不是方法排名**。
  - **v0.1 paper-scale Fig1 80000×500：** Uniform / E-process TPR=1.0 FDR=0 SAT=6490.298；E-process `post_burnin=True` 后 57400 pulls，wall=1696.318s rss=233.47MB。Mean-based TPR=0.474 SAT=`CENSORED` success=0.226。Fig3 Uniform SAT=724.272 FDR=0.004；algo3 SAT=9487.286 FDR=0 `post_burnin=True`。Fig2/Fig4 仍 `NOT_RUN`。FIGURE_ONLY，无官方表。
  - **v0.1 P1-A clean H=30000 30-seed（ADAPTED）：** E-process TPR=0.9666666666666667 vs Uniform 0.11666666666666667，第一次 post-burn-in 可分。SAT 因 success 不同不排名。
- **gap:** 与 e-PS 的「自适应抽样 + e-BH」接口相近，但鲁棒估计 / 污染模型不同。C1 候选；v0.1 已有 post-burn-in 对照，但仍是独立实现 + Lévy 未指定，不开 C-v1。
- **novelty risk:** 与 NeurIPS 2021 e-BMT 易混淆；必须对照 Figure 1/2 公式而非 `neilzxu/e_bmt`。短 horizon 上 Uniform≡E-process 容易被误读成「新方法没有增益」。

## 2. ICML 2026 — SCORE

- **作者 / 出处:** Qi Kuang, Bowen Gang, Yin Xia. ICML 2026 Main. PMLR v306. https://proceedings.mlr.press/v306/kuang26c.html
- **问题:** 在线 e-value FDR 把超过阈值的证据丢掉（overshoot），功率偏低。
- **动机:** \(I(y\ge 1)\le y-(y-1)_+\)，把超额证据退回 alpha-wealth。
- **方法:** SCORE-LOND / SCORE-LORD / SCORE-SAFFRON；SCORE+ 用最新拒绝数回溯分母（需 CPQD）。
- **公式:** \(O_j=(\alpha_j e_j-1)_+\)，\(C_j^{\mathrm{SCORE}}=(C_j-O_j)_+\)。SAFFRON 还先收紧 candidate penalty。§6.1 e-value \(e_t=\phi(X_t;3,6)/\phi(X_t;0,1)\)。\(\gamma_t=1/(t(t+1))\)。
- **定理:** 有限样本 FDR；SCORE 阈值点态不低于原方法；SCORE+ 的 FDR 在 CPQD 下成立。
- **假设:** 条件 e-validity；SCORE+ 另需 Conditional Positive Quadrant Dependence。独立 e-value + 单调阈值是 CPQD 的充分条件。
- **原 baseline / benchmark / figure:** e-LOND/LORD/SAFFRON。§6.1 独立 Gaussian mixture，\(T=1000\)，\(\pi_1\in\{0.3,0.8\}\)，\(\alpha=0.05\)，500 reps。§6.2 AR exponential（v0 默认后置）。
- **局限:** 无官方代码；SCORE+ 在不满足 CPQD 时不能用；真实数据 conformal e-value 文中不用 SCORE+。
- **复现发现:** 独立实现完整 wealth / overshoot，未简化成「拒绝后加点 α」。SCORE+ 只在声明 CPQD 时跑。逐步 wealth / null-only FDR / CPQD 门控测试通过后才跑 500。
  - v0 pilot 30-seed T=1000（不是 paper-scale）：π₁=0.3 SCORE+-LORD Power=0.42518634690970686 vs e-LORD 0.08347260729275957。
  - **v0.1 paper 500 α=0.05：** e-LORD / SCORE-LORD / SCORE+-LORD π₁=0.3 Power = 0.08319242249651712 / 0.09041407826333013 / 0.42791961705610515；ratio 5.143733097494788 vs paper 5.19（rel 0.89%）。e-SAFFRON / SCORE-SAFFRON / SCORE+-SAFFRON = 0.09958725523941843 / 0.12229936913940857 / 0.4089496487752092；ratio 4.106 vs 4.13。π₁=0.8 SCORE+-LORD Power=0.5109161050204014 FDR=0.0007873154948340546。FDR 均远低于 α。α≥0.10 / AR Table 3 / Yeast / MI 仍 `NOT_RUN` 或 `BLOCKED_NO_DATA`。无 `INDEPENDENT_FULL_MATCH`。
  - **v0.1 P1-B** 同 §6.1 流 30-seed：SCORE+-LORD Power=0.425186 FDR=0.001328，与 paper-scale 同量级。
- **gap:** 与 UAI donation / closed 都是「把多余财富再分配」，计算与假设不同。C2 候选。不开 C-v1。
- **novelty risk:** 若只把 SCORE 写成「拒绝后加点 α」即与原文不符。不得用功率差宣称已发明 C2。

## 3. UAI 2026 — online e-closure and compound e-values

- **作者 / 出处:** Ziyu Xu, Lasse Fischer, Aaditya Ramdas. UAI 2026，PMLR v337. **非 CCF-A Main。** https://proceedings.mlr.press/v337/xu26a.html
- **问题:** 任意依赖下改进在线 FDR / **SupFDR**，并降低 closed 方法的 \(O(t^2)\) 成本。
- **动机:** 离线 e-closure 不能直接搬到无穷流；donation 构造在线 compound e-value，单步 \(O(\log t)\)。
- **方法:** Closed e-LOND / r-LOND（动态规划 \(O(t^2)\)）；Donation e-LOND / r-LOND（\(O(\log t)\)）。二者都严格改进 e-LOND，但不一定彼此点态支配。
- **公式:** e-LOND \(\alpha_t=\delta\gamma_t(|R_{t-1}|+1)\)；默认 \(\gamma_t=1/(t(t+1))\)。Donation 用超额财富 \(\bar W_t\) 抬高当前阈值。
- **定理:** online SupFDR e-closure（Theorem 1）；donation e-LOND 控制 SupFDR 且严格改进 e-LOND（Theorem 8）。
- **假设:** 任意依赖 e-value / p-value；increasing e-collection；\(\gamma\) 可和为 1。
- **原 baseline / benchmark / figure:** e-LOND, r-LOND, closed, donation。Local dependence：\(m=200\)，\(\mu_0=0,\mu_1=3\)，\(L=100\)，\(\Sigma_{ij}=0.5^{|i-j|}\)（\(|i-j|\le L\)），\(\delta=0.1\)，**200 trials**。Runtime 网格可到 \(m=3000\)（默认跳过）。NYC taxi 默认跳过。
- **局限:** 公开 `neilzxu/eclosure` 对应离线论文 arXiv:2509.02517（`closedeBH`/`closedBY`），不是 UAI 在线算法。`evalue-omt` 是 AISTATS 2024。Mac 上 C++ `_cebh` 在 v0 `.venv` 不可用。r-LOND 正文未写清 \(f_t\)；本实现用 \(E=1/P\)。
- **复现发现:** 在线方法 `independent_reimplementation`。C++ `_cebh` unavailable，不影响在线路径。P0 local-dep、δ=0.1、pilot 30-seed（不是 200-trial paper-scale）：
  - Closed e-LOND：FDR=0.0027777777777777775，SupFDR=0.006666666666666667，Power=0.08619363902157415，Runtime=20.633s。
  - Donation e-LOND：FDR=0.0030303030303030303，SupFDR=0.006666666666666667，Power=0.06240989556655258，Runtime=0.184s。
  - e-LOND：FDR=0.004166666666666667，SupFDR=0.006666666666666667，Power=0.058288403388734096。
  - r-LOND：FDR=0.0017543859649122805，SupFDR=0.005555555555555555，Power=0.14629723390483573。
  - Donation r-LOND：FDR=0.03434570927548704，SupFDR=0.04672753172753173，Power=0.22392690929939754。
  - Closed r-LOND：FDR=0.09063876463740132，SupFDR=0.13512808070528035（>δ=0.1），Power=0.42568089583103713。这是独立实现 + \(E=1/P\) 校准下的数字，**不是**定理反例，也不是 CCF-A Main 结论。
  - NYC taxi / m=3000 / paper-scale 200 仍 `NOT_RUN`（v0）。
  - **v0.1 paper m=200 n=200 π₁=0.3：** e-LOND Power=0.06873919409029026 FDR=0.000625；Donation e-LOND 0.07853356888718559 / 0.001326；Closed e-LOND 0.10080299664358812 / 0.002023 wall=129.758s；r-LOND 0.166789 / 0.003464；Donation r-LOND 0.244008 / 0.041545；Closed r-LOND 0.433923 / 0.091508 SupFDR=0.150654。Runtime m=3000 n=80 donation/e/r-LOND wall≈801.5s rss≈916MB；Closed m=3000 `BLOCKED_COMPUTE` ≈31.89h。NYC CSV 已下载，runner 未接线 → 仍 `NOT_RUN`。
- **gap:** 与 SCORE overshoot refund 同属财富再分配，错误度量（FDR vs SupFDR）与计算复杂度不同。
- **novelty risk:** 把 UAI 标成 CCF-A、或把离线 e-Closure 仓库当成 UAI 2026 官方在线代码，都会造成 venue / 复现错误。Closed r-LOND 的 SupFDR>δ 只能驱动实现核对，不能当新定理。

## 4. arXiv:2609.26651 — e-PS

- **作者 / 出处:** Zhanran Lin, Wanteng Ma, Zhimei Ren, Yuting Wei. arXiv:2609.26651，**预印本，不是已发表 CCF-A。**
- **问题:** 自适应选臂做多重检验：用尽量少的样本发现全部 non-null，anytime FDR，拒绝集 nested。
- **动机:** e-value 既做检验（e-BH）又做抽样奖励（log increment 的后验抽样）。
- **方法:** Algorithm 1 e-PS：每个假设用 surrogate reward 上的后验抽一个合成奖励，抽最大者；e-BH 得到 \(R_t\subseteq R_{t+1}\)。
- **公式:** 条件有效 e-increment；Gaussian 均值检验 KL 与 sub-Gaussian log-LR；实现用 \(v_{k,t}=1.1\hat\sigma_{k,t}^2\)（n<2 用 1.0）。原文 \(\theta_k=0.02k\cdot B_k\)，\(B_k\sim\mathrm{Bern}(0.1)\)。
- **定理:** 任意停时 FDR；nested rejection；发现全部 non-null 的高概率样本复杂度（simple-vs-simple 有匹配下界）。
- **假设:** 条件有效 e-increment；log e-increment 的 sub-Gaussian / 方差代理。
- **原 baseline / benchmark / figure:** Uniform；Greedy（Xu et al. 2021）。§6：\(K=50\)，1D Gaussian 与 1D Student-t(5)；simple-vs-simple vs composite 分开；\(\alpha=0.05\)；**500 trials**。跳过 5D、Jester、LLM watermark。
- **局限:** 无官方代码；方差代理需调；污染下非鲁棒 increment 没有文中保证。Student-t 原文写 noncentrality，本实现用 location-shift。
- **复现发现:** 独立实现。预印本。P0 1D Gaussian pilot 30-seed、horizon=4000（不是 500-trial）：
  - Oracle：e-PS TPR=0.5499999999999999、FDR=0.006666666666666667；Greedy TPR=0.4277777777777777、FDR=0.02333333333333333；Uniform TPR=0.3388888888888889、FDR=0.02222222222222222。
  - Adaptive：e-PS TPR=0.35555555555555557、FDR=0.01944444444444444；Greedy 0.4222222222222223 / 0.03333333333333333；Uniform 0.27777777777777773 / 0.027777777777777776。
  - Samples@Target TPR 全 `NOT_RUN`（未达 0.95）。
  - Student-t location-shift pilot Oracle：e-PS TPR=0.4666666666666667、FDR=0.015000000000000001；Greedy 0.3277777777777778；Uniform 0.24444444444444446。
  - P1-A 把 Oracle 假设备择改成 μ=1（adapted）。污染下非鲁棒 increment 的 FDR=0.9600000000000002，标 `NOT_COMPARABLE`，不是定理反例。
  - 5D / Jester / watermark `NOT_RUN`（v0）。
  - **v0.1：** paper 500 `BLOCKED_COMPUTE`（1-seed H=50000 gaussian eps/oracle 44.562s TPR=1 SAT=28253；500≈80h）。只跑 fig2a/2c smoke 3×H=400。Jester TLS/404、watermark 预生成流未发布 → `BLOCKED_NO_DATA`。P1-A 共用协议里的 e-PS 是 μ=1 `ADAPTED_PROTOCOL`，不是本文复现。污染非鲁棒 increment FDR=0.9600000000000002 仍 `NOT_COMPARABLE`。
- **gap:** 与 AAAI robust bandit 同是自适应抽样 + 多重检验，污染模型几乎没覆盖。C1 的对照轴。
- **novelty risk:** 预印本状态可能变；不能把 e-PS 写成已发表 CCF-A baseline。P1-A 的 μ=1 Oracle 不是原文设定，不能当 e-PS 论文复现。
