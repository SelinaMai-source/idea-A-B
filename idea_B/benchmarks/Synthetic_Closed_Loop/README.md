# Synthetic Closed Loop

Idea B 的合成环境，技能维数为 3（允许范围 2–5）。短时域、小人群，用于烟测而不是大规模排行榜。

## B1 — 外生缺失诊断

弱技能的自然观测率按日历衰减，**不依赖**当前策略。观测表现可以维持在高位，同时弱技能对应的 \(W_T\) 信息消失。这是诊断，不是策略诱发坍缩。

## B2 — 策略诱发的反馈坍缩（真闭环）

当前参数给 query 打分，策略只服务预测质量最高的一部分，自然标签只来自被服务的 query，观测设计 Gram 矩阵和标签更新参数，新参数成为下一轮策略。人群本身不外生地抽走弱技能；弱技能还在总体里，只是策略不再看见它。

## B3 — 可恢复 vs 不可恢复

- `B3_recoverable`：与 B2 相同的闭环，弱技能仍在总体中，审计能恢复该方向的信息。
- `B3_unrecoverable`：弱技能坐标从观测特征中被投影掉，额外预算也不能识别该参数。
