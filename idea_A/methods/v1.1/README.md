## 估计量

- `μ_Y(x)=E[Y|X]`：只在 `A=1` 上做 ridge。自然观测 `S=1, A=0` 不进入回归。
- `μ_P(x)=P(Y>0|X)`：单独的 logistic。禁止把连续 `μ_Y` 直接当概率。
- `μ_V(x)=E[w(X)Y|X]`：当 `w` 是已知层密度比 `p*(z)/p(z)` 时，`μ_V(x)=w(x)μ_Y(x)`。AIPW 残差是 `w(Y-μ_Y)`，不是 `wY-μ_Y`。
- 静态：2 折 cross-fit，折外预测，不用隐藏标签。
- 序贯：用过去轮拟合 nuisance，估当前轮。普通打乱 CV 在自适应抽样下会泄漏未来：未来的 `q` 和（经策略更新后的）`Y` 分布依赖过去的估计。

名义 95% 区间冻结为影响函数 Wald：`ψ̄ ± 1.959963984540054 · sd(ψ)/√n`。所有 v1.1 方法使用同一公式族。

## 倾向与双重稳健性的范围

已知审计 `q` 才是 MNAR 下的识别通道。

`P(O=1)=1-(1-p_S)(1-q)` **只在** `p_S` 不依赖未观测 `Y` 时使用。自然通道 MNAR 时不得把该乘积式当作识别公式。

普通 AIPW 的双重稳健性 **只针对**「审计缺失、`q` 已知、`A ⊥ Y | X, history`」。有审计不等于把 MNAR 变成 MAR，也不等于对任意自然通道 MNAR 成立双重稳健。

## A-v1.1b 方差公式（可计算近似，不是新最优设计定理）

把折外回归当作固定。审计残差 `e_i = Y_i - μ_Y(X_i)`，AIPW 影响函数

```text
ψ_i = μ_Y(X_i) + (A_i / q_i) e_i
Var(ψ_i | X_i) = σ²(X_i) (1 - q_i) / q_i
```

层内 `q_h` 为常数、`σ̂_h²` 只由该层审计残差估计时，

```text
σ̂_h² = (1 / n_{h,A}) Σ_{i ∈ h, A_i=1} e_i²
n Var(μ̂) ≈ Σ_h W_h σ̂_h² (1/q_h - 1),    W_h = n_h / n
```

依赖 `q` 的部分是 `Σ_h n_h σ̂_h² / q_h`。在 `Σ_h n_h q_h = b n`、`0 ≤ q_h ≤ 1` 下最小化，得到 Neyman 规则 `q_h ∝ σ̂_h`，再把 `mean(q)` 拉回 `b`。这是把教科书分层分配用在 AIPW 残差上的可计算近似，**不是**新的最优性定理。没有审计残差时退回均匀分配。静态实现是两阶段：先均匀试点，再用试点审计残差分配剩余单位。

A-v1.1c 在该规则上：(1) 用剩余期望审计条数除以剩余单位作为本轮预算；(2) 对 `|mean(π_t|h) - mean(π_{t-1}|h)|` 大的层把 `σ̂_h` 乘上 `1 + κ clip(|Δπ_h|/scale, 0, cap)`。超参写在 `config.yaml`，不在评价种子上改。
